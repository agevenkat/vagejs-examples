# Kettlemark documentation

Kettlemark renames photos and videos by the date they were taken. These pages explain how it works and how to use it.

## How it works

Most cameras and phones store the moment a photo was taken inside the file, in a part called the EXIF data. Videos keep a similar creation date. Kettlemark reads that date and builds a new file name from it, using a pattern you can change.

It never edits the photos themselves. It only changes file names, and it writes a small log so every rename can be undone.

## Requirements

Kettlemark runs on macOS, Windows and Linux. It reads JPEG, HEIC, PNG, TIFF, most camera RAW formats (CR3, NEF, ARW, DNG) and MP4 and MOV videos.
