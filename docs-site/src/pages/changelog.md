# Changelog

What changed in each release of Kettlemark.

## 1.4.0

<span class="stamp">'26 09 30</span>

- HEIC photos from recent phones.
- `kettlemark config` shows where each setting came from.

## 1.3.0

<span class="stamp">'26 06 12</span>

- `--fallback filename` reads dates from names like `Screenshot 2026-03-14 at 09.15.22.png`.
- Undo works per folder after a `--recursive` rename.

## 1.2.0

<span class="stamp">'26 02 03</span>

- Camera RAW files: CR3, NEF, ARW and DNG.
- The `{camera}` pattern token.
